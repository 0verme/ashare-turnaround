# Historical PIT replay validation summary

This tracked file is the safe, contract-level summary for issue #32.  Runtime
corpus artifacts are intentionally not committed.  The measured local summary
is generated by `replay-validate` at
`docs/pit-replay-validation-summary.md` (or the `--summary` path) and is kept
separate from RAW data.

## Contract

- Contract version: `pit-replay-validation-v1`
- Monthly rule: `monthly-anchor-15-v1`
- Requested target range: `2017-01` through `2026-12`
- Anchor: fixed 15th, then first same-month `trade_cal` open session
- Formal Top-N: current `score-v2` plus `evidence-confidence-v1`, gated by
  `ranking_eligible == true`
- Regime: `market-regime-v1`, benchmark `000300.SH`, trailing trend/drawdown
  rule using only observations through each selected session

The repository does not contain the real historical RAW corpus or large replay
JSON files. Running the documented command is therefore required before
interpreting local snapshot counts. Missing or incomplete inputs remain
`INCOMPLETE`/`UNAVAILABLE`; they are never represented as `READY`.

## Correctness-only findings

- Financial visibility is bounded by `actual_available_date <= as_of`, including
  the original/revised version boundary fixture.
- Market and benchmark evidence is bounded by the selected trading session.
- Missing benchmark evidence stays `UNKNOWN`; no stock-only fallback is used.
- Current `stock_basic` name/status/industry/board fields are
  `UNSUPPORTED_PIT` and are never backfilled into historical rows.
- Every candidate retains feature evidence, score partialness, coverage,
  confidence, unknown groups, ranking eligibility, rejection reasons, and
  provenance in the per-snapshot artifact.
- The fixed manual-review artifact contains Top-3, high-score ineligible,
  unknown-heavy, and universe-exclusion cases when available.
